# What the items need from the spell module

The spell module (`pf2e-automatic-resolution`) casts the items' spells. What an item needs from it is kept here; each item's rule is a line of its card until it's built. *(Started 2026-10-27, from the first six-agent batch; rows 7 on from batches 2–4, the same day.
